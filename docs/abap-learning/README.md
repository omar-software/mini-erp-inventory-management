# ABAP Learning Notes

This folder contains small ABAP learning examples related to the Mini ERP Inventory Management System.

The goal is to connect the ERP business logic of the project with basic ABAP concepts that are relevant for Junior ABAP Developer roles.

## Covered Topics

- ABAP Reports
- Internal Tables
- Loops
- Simple output with WRITE
- ABAP OO basics
- Material and stock related examples
- ERP-inspired business logic

## Relation to the Main Project

The main project was built with Java Spring Boot and Angular.  
These ABAP examples show how similar ERP-related ideas could be represented in ABAP.

Examples:

- Material list report
- Stock overview
- Simple service class for stock calculation
